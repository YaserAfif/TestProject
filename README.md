# دفتر حسابات — نسخه ۸

نسخهٔ ساده برای ثبت معاملات روزانه با قابلیت افزودن واحدهای پولی مختلف.

- روزنامچه با حساب، گرفت، انتخاب رنگی ارز و طلب در یک ردیف فشرده.
- طریقه ثبت (خزانه پیش‌فرض / بدون مدرک) زیر ردیف مبلغ.
- افزودن یا حذف ارزهای بدون معامله از تنظیمات؛ معاملات قبلی AFN باقی می‌مانند.
- حساب و راپور بر اساس ارز، بدون جمع کردن ارزهای متفاوت.
- ارقام فارسی/انگلیسی و جداکننده هزارگان، تاریخ شمسی، منوی شناور موبایل.
- واترمارک یاسر عفیف با لینک وبسایت و متن حفظ حقوق.

**مهم:** این نسخه تبدیل ارز یا محاسبه نرخ مبادله ندارد. اطلاعات در localStorage همان مرورگر می‌مانند. پیش از جایگزینی پروژه، از تنظیمات پشتیبان JSON بگیرید و نسخه را روی داده‌های آزمایشی نیز بررسی کنید.

GitHub Pages: فایل‌های داخل ZIP را در شاخه اصلی مخزن جایگزین کنید.
