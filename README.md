# دفتر حسابات — نسخه ۴

برنامه وب سبک برای تلفن و کمپیوتر، قابل میزبانی روی GitHub Pages.

## قابلیت‌ها
- روزنامچه مرکزی برای ثبت/ویرایش/حذف معاملات طلب و گرفت و محاسبه باقی حساب
- حساب‌های جداگانه با ایجاد حساب، شماره تماس، جستجو و راپور مختص هر حساب
- تاریخ میلادی برای ذخیره استاندارد، نمایش تقویم شمسی افغانستان به صورت پیش‌فرض
- راپور عمومی با فیلتر حساب و تاریخ، چاپ و CSV؛ همچنین خروجی اکسل معاملات
- تنظیمات عنوان، تقویم و ظاهر روشن/تاریک
- پشتیبان کامل JSON شامل معاملات، حساب‌ها و تنظیمات، بازیابی پشتیبان‌های قدیمی
- گزینه خزانه / بدون مدرک هنگام ثبت. تغییرات خزانه در راپور به صورت **خالص معاملات دارای حالت خزانه** نمایش می‌یابد، نه موجودی افتتاحیه.

## حفظ اطلاعات
کلید معاملات قبلی `hesabket.records.v1` عمداً تغییر نکرده است. حساب‌ها از سوابق قدیمی شناسایی می‌شوند. پیش از جایگزینی فایل‌ها پشتیبان JSON بگیرید. اطلاعات فقط در حافظه مرورگر همان دامنه و دستگاه است؛ همگام‌سازی آنلاین و سرور در این نسخه وجود ندارد.

## انتشار
محتویات پوشه را در ریشه مخزن GitHub Pages قبلی جایگزین کنید. سپس صفحه را تازه‌سازی نمایید. فایل `sw.js` کش نسخه جدید را فعال می‌کند. در صورت مشاهده نسخه قدیمی دوباره بارگذاری کنید.
