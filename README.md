# دفتر حسابات — نسخه ۷ (اصلاح منوی موبایل)

- منوی شناور + در پایین سمت راست، مناسب استفاده با یک دست؛ بازشدن گزینه‌ها به سمت بالا.
- هماهنگی جای منو با ناحیهٔ قابل‌دید صفحه هنگام بازشدن صفحه‌کلید موبایل (Visual Viewport).
- اصلاح خطای اجرای JavaScript که باعث کارنکردن کلیدهای منو و سایر بخش‌ها می‌شد.
- نسخه جدید کش Service Worker و دریافت فایل تازه از شبکه برای جلوگیری از ماندن نسخه قدیمی.
- حفظ ساختار اطلاعات نسخه‌های قبلی در حافظه مرورگر.

## نصب
پیش از جایگزینی فایل‌ها، از بخش تنظیمات نسخه فعلی پشتیبان بگیرید. فایل‌های این پوشه را در ریشه همان مخزن GitHub Pages جایگزین کنید؛ در صورت نمایش نسخه قبلی صفحه را یک بار ببندید و دوباره باز کنید.
