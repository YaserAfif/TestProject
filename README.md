# دفتر حسابات — نسخه ۶ سبک

این نسخه از نسخه ۵ ساخته شده و داده‌های قبلی در همان localStorage نگه داشته می‌شوند.

- ورود مبلغ با رقم‌های فارسی، عربی و انگلیسی؛ جداکننده سه‌رقمی در زمان تایپ؛ نمایش عددها به شکل انگلیسی
- روزنامچهٔ گرفت / طلب با قفل‌کردن خانه مقابل
- منوی کشویی + برای صفحات
- راپور انتخابی مخصوص یک حساب همراه با انتخاب بخش (معاملات حساب، خزانه یا بدون مدرک) و تاریخ
- بکاپ و بازیابی در تنظیمات

## اجرا
`index.html` را باز کنید یا تمام فایل‌ها را در مخزن GitHub Pages قبلی جایگزین کنید. برای نگه‌داشتن اطلاعات قبلی حتماً روی همان دامنه و مرورگر اجرا کنید.

**مهم:** قبل از جایگزینی فایل‌ها در تنظیمات از اطلاعات بکاپ JSON بگیرید. اطلاعات محلی با پاک‌کردن حافظه مرورگر ممکن است حذف شوند.
